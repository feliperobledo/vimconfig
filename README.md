# vimconfig

My neovim configuration files

## Stack

| Plugin                              | Role                           | Responsibilities                                                                             | Interactions                                                                                                                                         |
| ----------------------------------- | ------------------------------ | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `neovim/nvim-lspconfig`             | LSP client configuration layer | Register language servers with shared `on_attach` and capabilities, apply per-server tweaks. | Consumes capabilities from `cmp-nvim-lsp`, works with `mason-lspconfig`, feeds diagnostics to native tooling such as `vim.diagnostic` and Telescope. |
| `williamboman/mason.nvim`           | External tool manager          | Install and update language servers, formatters, and linters from the Mason registry.        | Uses the registry API to auto-install required language servers listed in `lua/plugins/mason.lua`.                                                  |
| `hrsh7th/nvim-cmp`                  | Completion engine              | Provide completion UI, sorting, and mappings in insert and command-line modes.               | Aggregates sources (LSP, buffer, path) and calls LuaSnip for snippet expansion.                                                                      |
| `hrsh7th/cmp-nvim-lsp`              | LSP completion source          | Surface LSP completion items in `nvim-cmp` and expose `default_capabilities()`.              | Capabilities must be passed to every `lspconfig` server; relies on active LSP clients.                                                               |
| `hrsh7th/cmp-buffer`                | Buffer completion source       | Offer buffer words as completion suggestions.                                                | Loaded as an `nvim-cmp` source alongside LSP entries.                                                                                                |
| `hrsh7th/cmp-path`                  | Filesystem completion source   | Suggest filesystem paths in insert or command-line completion.                               | Enabled through the `nvim-cmp` source list; complements command-line completion.                                                                     |
| `hrsh7th/cmp-cmdline`               | Command-line completion source | Provide `:` and `/` completion via `nvim-cmp`.                                               | Configured with `cmp.setup.cmdline`; pairs with buffer/path sources.                                                                                 |
| `L3MON4D3/LuaSnip`                  | Snippet engine                 | Expand and manage snippets with jump and choice support.                                     | Invoked by `nvim-cmp`’s snippet expansion; loads collections like `friendly-snippets`.                                                               |
| `rafamadriz/friendly-snippets`      | Snippet collection             | Supply ready-to-use VSCode-format snippets.                                                  | Imported by LuaSnip loaders so entries appear inside `nvim-cmp`.                                                                                     |
| `folke/neodev.nvim`                 | Neovim Lua helper              | Improve `lua_ls` settings for editing Neovim configs and plugins.                            | Augments `lua_ls` setup executed through `nvim-lspconfig`; assumes `cmp-nvim-lsp` capabilities.                                                      |
| `j-hui/fidget.nvim`                 | LSP progress UI                | Display asynchronous LSP request progress without blocking editing.                          | Hooks into handlers registered via `nvim-lspconfig`.                                                                                                 |
| `folke/trouble.nvim`                | Diagnostics/workspace list     | Visualize diagnostics, references, and quickfix items in a dedicated panel.                  | Consumes `vim.diagnostic` data from LSP servers and integrates with Telescope pickers.                                                               |
| `Hoffs/omnisharp-extended-lsp.nvim` | OmniSharp navigation helper    | Provide enhanced definition handlers for C# LSP responses.                                   | Used by `lua/config/lsp/servers/init.lua` to mirror CoC's precise go-to-definition behavior.                                                         |
